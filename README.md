# Job Application Tracker

A comprehensive tool to track your job applications, built with Python.

## Features
- Track job applications efficiently.
- Automated backups to ensure your data is safe.
- Simple and easy-to-use command-line interface.

## Prerequisites
- Python 3.x
- `pandas` library (for Excel/data handling)

## Setup
1. Clone this repository:
   ```bash
   git clone https://github.com/pshree2003/job-application-tracker.git
   ```
2. Navigate to the project directory:
   ```bash
   cd job-application-tracker
   ```
3. Install dependencies:
   ```bash
   pip install pandas openpyxl
   ```

## Usage
Run the main tracker script:
```bash
python job_tracker.py
```
